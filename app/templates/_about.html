{{ app_name }} archive les bulletins météo HF entre le radio-club {{ club_callsign }} et les bateaux de la flotte Golden Globe Race. Le club émet un bulletin météo tous les jours à {{ time_utc }} TU sur {{ tx_mhz }} MHz USB (QRG nominale 14.135 MHz) depuis {{ bulletin_tx_label | default('F6KUF') }} {% if bulletin_tx_from_tahiti %}(Michel, relais Tahiti après Bonne-Espérance){% endif %}. Deux KiwiSDR enregistrent cette QRG : l’un près de l’émetteur, l’autre près de la flotte. Les accusés de réception sont écoutés sur {{ ack1_mhz }} MHz USB et {{ ack2_mhz }} MHz USB (QRG ± {{ qrg_tolerance_khz }} kHz). Tous les jours à {{ buddy_time_utc }} TU, un buddy call est écouté sur {{ '%.0f'|format(buddy_main_khz) }} kHz USB (principale) et {{ '%.0f'|format(buddy_alt_khz) }} kHz USB (secours), depuis 4 KiwiSDR choisis pour la propagation (NVIS et saut 1 hop) vers le centroïde des skippers suivis ({{ buddy_skippers_short }}). Le bulletin et les ACK sont enregistrés en parallèle. Les QRG se règlent dans Setup.

Fonctionnement

  • Centroïde des skippers suivis via le tracker Yellowbrick GGR 2026.
  • Carte 2D ou globe 3D (commutateur) : flotte, Kiwi, QTH d’émission. Le panneau droit (Trafic / Setup / À propos) se replie comme un KiwiSDR.
  • Bulletin 14.135 MHz : Kiwi près de F6KUF (ou Tahiti après le cap de Bonne-Espérance) et Kiwi près des skippers cochés, VFO calé sur 14.135000 MHz.
  • Screencast de l’interface SDR (waterfall / VFO) muxé avec l’audio USB 12 kHz.
  • Replay multipistes : volume, mute et timeline TU.
