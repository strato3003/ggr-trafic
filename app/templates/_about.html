GGR Vacations archive les bulletins météo HF entre le radio-club {{ club_callsign }} et les bateaux de la flotte Golden Globe Race. Le club émet un bulletin météo tous les jours à {{ time_utc }} TU sur {{ tx_mhz }} MHz USB (QRG nominale ± {{ qrg_tolerance_khz }} kHz) et écoute les accusés de réception sur {{ ack1_mhz }} MHz USB et {{ ack2_mhz }} MHz USB (QRG ± {{ qrg_tolerance_khz }} kHz). Tous les jours à {{ buddy_time_utc }} TU, un buddy call est écouté sur {{ '%.0f'|format(buddy_main_khz) }} kHz USB (principale) et {{ '%.0f'|format(buddy_alt_khz) }} kHz USB (secours), depuis 4 KiwiSDR choisis pour la propagation (NVIS et saut 1 hop) vers le centroïde des skippers suivis ({{ buddy_skippers_short }}{% if buddy_include_fleet %} + flotte{% endif %}). Le bulletin et les ACK sont enregistrés en parallèle. Les QRG se règlent dans Setup.

Fonctionnement

  • Position moyenne de la flotte via le tracker Yellowbrick GGR 2026.
  • Globe 3D central : flotte, Kiwi, QTH d’émission. Le panneau droit (Trafic / Setup / À propos) se replie comme un KiwiSDR.
  • Chaque trafic (météo ou buddy call) cherche 4 récepteurs répartis, puis propose uniquement la table de mixage (voies sans audio grisées).
  • Screencast de l’interface SDR (waterfall / VFO) muxé avec l’audio USB 12 kHz.
  • Replay multipistes : volume, mute et timeline TU.
